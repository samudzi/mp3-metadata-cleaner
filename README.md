# SonicClean — Bulk MP3 Metadata & Cover Art Cleaner

**SonicClean** is a client-side web application designed to clean, format, and organize MP3 ID3 tags, scrub AI-generated metadata (such as Suno AI watermarks), and embed 1:1 square cover art in bulk.

All file processing runs locally inside your browser — no audio files or credentials are ever uploaded to an external server.

---

## 🌟 Key Features

### 1. 🧹 Suno AI Metadata Scrubber
AI music generators like Suno embedded prompts, generation UUIDs, model version tags, and URLs into MP3 file headers and titles. SonicClean automatically detects these artifacts and cleans them with 1-click:
- **Title Scrubbing**: Strips bracketed style tags like `[Upbeat Pop 120bpm]` or `[v3.5]`.
- **Artist & Album Cleanup**: Resets default fields like `"Suno AI"` or `"Generated by Suno"`.
- **Parameter Purging**: Clears AI prompt parameters, seeds, and URLs from comment frames and `TXXX` metadata fields.
- **Lyrics Cleaning**: Strips AI directives (e.g. `[Verse 1]`, `[Style: Synthpop]`, `[Guitar Solo]`) from unsynchronized lyrics (`USLT`).

### 2. 🗂️ Bulk Album Metadata Editor
Apply changes across all or selected tracks at once:
- **Batch Fields**: Artist, Album, Album Artist, Genre, Release Year, and Comments.
- **Auto Track Numbering**: Re-sequence tracks in order (`01`, `02`, `03`...).
- **Title Case Converter**: Convert track names to proper Title Case capitalization.
- **Find & Replace**: Regex and case-sensitive text replacement across titles, artists, albums, and lyrics.

### 3. 🖼️ Batch Cover Art Processor
- **Auto-Square Crop**: Center crops images to a 1:1 square aspect ratio.
- **Dimension Presets**: 500×500 (Car stereos), 800×800 (Standard HD), 1000×1000 (Hi-Res).
- **Clipboard & Extraction**: Paste images directly from clipboard or extract artwork from an existing track in the batch.

### 4. 📝 Lyrics Editor & Audio Player
- **Embedded Audio Player**: Preview audio tracks directly in browser.
- **USLT Lyrics Editor**: Add, edit, or batch-clear song lyrics.

### 5. 📦 Zip Batch Export
Re-writes fresh **ID3v2.3** tags into MP3 files and exports the entire cleaned album as a single `.zip` file, preserving track titles and numbering.

## 🚀 How to Use

### Step 1: Import MP3 Files
1. Drag and drop MP3 audio files or an entire folder into the upload zone.
2. *Testing without files?* Click **Load Demo Suno Album** in the top right to load sample tracks populated with Suno AI tags.

### Step 2: Clean Suno AI Tags (If Detected)
- If Suno metadata is detected, an warning banner appears with a breakdown of detected artifacts.
- Click **Clean All Suno Tags** to automatically scrub prompt brackets, clean track names, and purge comment parameters.

### Step 3: Batch Edit Metadata & Cover Art
1. **Edit Album Info**: Use the **Bulk Album Metadata** bar to set Artist, Album, Year, or Genre across selected tracks.
2. **Title Tools**: Use quick action buttons to auto-sequence track numbers (`01, 02...`), strip leading track numbers from title names, or title-case text.
3. **Cover Art**: Click **Cover Art Processor** to upload an album cover, select target dimensions (e.g. 800×800), and apply to all tracks.

### Step 4: Preview & Export
1. Click the **Play** button on any track to preview playback.
2. Enter an **Archive Name** in the export panel and click **Download Cleaned Album (.zip)**.

## 🔒 Privacy & Safety

- **100% Local Browser Execution**: Uses Web APIs (`music-metadata-browser`, `browser-id3-writer`, and HTML5 Canvas) to parse and write ID3 tags directly in memory.
- **Zero Server Uploads**: Your music stays on your local device.

- **Archiving**: `jszip` & `file-saver`
